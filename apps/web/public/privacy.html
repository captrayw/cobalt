cobalt privacy

cobalt collects nothing about you.

There is no account, no sign-in, no analytics, no advertising and no tracking. The iPhone app makes no network requests. It opens a web page only when you tap the acolorcompany.com link on its About screen, and that page opens in Safari.

What stays on your device

The sessions you watch, the pages you linger on (cobalt's memory) and your settings are kept in the app's own storage on your device. They are never sent anywhere. They leave the device only if you export them yourself, with Export on the Memory screen, which makes a file that you keep.

Deleting it

Reset memory, on the Memory screen, clears the remembered pages and the stored sessions. Deleting the app deletes everything it stored.

The web version

The web version at captrayw.github.io/cobalt is served by GitHub Pages. GitHub may keep standard request logs, such as IP addresses, as described in GitHub's privacy statement. cobalt itself adds nothing to them.

Children

cobalt collects no information from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with its date.
